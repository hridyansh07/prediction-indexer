# UI brand assets

- `kalshi.svg`: current 2026 Kalshi wordmark from Kalshi's official brand kit,
  mirrored by Wikimedia Commons. Use follows Kalshi's published brand terms.
- `polymarket.svg`: `icon-blue.svg` from Polymarket's official logo archive.
- `limitless.svg`: first-party `https://limitless.exchange/favicon.svg`.

The UI uses these marks only to identify evidence sources and does not imply an
endorsement or partnership. Counter-Strike 2 and League of Legends marks are
loaded from Valve's first-party CDN and the Wikimedia mirror of Riot's mark,
respectively; all marks remain the property of their owners.
